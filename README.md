# maas_kontrol
Diyanet İşleri Başkanlığı İl ve İlçe Müftülüklerinin Kullanımı için tasarlanmıştır. 

Maaş unsurlarındaki hataların tespiti amacıyla hazırlanmıştır. 

İnternet bağlantısına ihtiyaç duymadan; tüm sistemlerde ve cihazlarda çalışacak şekilde tasarlanmıştır. 

Kullanım talimatları ve açıklamalar program içinde mevcuttur. 

Maaş-Kontrol-2026-09-08.html veya index.html dosyasını bilgisayarınıza indirerek kullanabilirsiniz. 

Programı test etmek için "Demo Bordro Dokumu.xlsx" ve "Demo Personel Rapor.xls" dosyalarını kullanabilirsiniz.

Demo dosyalar Maaş-Kontrol-2026-07-03.html ve öncesi için düzenlenmiştir.

Maaş-Kontrol-2026-09-08.html dosyası ile çalışacak demo dosyası düzenlenmemiştir.
